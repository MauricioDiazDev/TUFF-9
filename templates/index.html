¿Qué es TUFF-9?

TUFF-9 es una aplicación web para el reconocimiento automático de rostros y matrículas, desarrollada como Trabajo Fin de Grado. Se basa en Django, emplea Celery para la gestión de tareas asíncronas, utiliza InsightFace y FAISS en el componente de reconocimiento facial, e integra YOLOv8 junto a un servicio OCR para la detección de vehículos y placas.

{# — Objetivos — #}

Objetivos

  • Implementar un sistema fiable de reconocimiento facial.
  • Automatizar la detección y lectura de matrículas.
  • Gestionar el procesamiento en segundo plano de forma eficiente.
  • Ofrecer una interfaz clara e intuitiva para la visualización de resultados.
